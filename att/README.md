# Attendance Planner Frontend

Track and plan attendance per subject with 75% minimum requirement enforcement.

## Features

- Upload timetable and academic calendar
- Plan future attendance with real-time warnings
- Summary dashboard with charts

## Tech Stack

React 18 + TypeScript + Vite + Tailwind CSS + Zustand

## Timetable Upload

**💡 Tip:** Use an LLM (ChatGPT, Claude, etc.) to convert your timetable data to the required JSON format. Simply paste your timetable and ask it to format it according to the template.

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
