# Attendance Planner Backend

FastAPI backend for attendance tracking with 75% threshold enforcement.

## Features

- Calendar & timetable processing
- Attendance calculation & warnings
- What-if simulations

## Tech Stack

FastAPI + Pydantic + Pandas

## Getting Started

```bash
pip install -r requirements.txt
python -m uvicorn app.main:app --reload
```

API Docs: http://localhost:8000/docs
